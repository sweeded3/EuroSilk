# EURO SILK — статический сайт для GitHub Pages

Готовый набор файлов для публикации учебного сайта EURO SILK на GitHub Pages.

## Состав

- `index.html` — главная страница сайта.
- `privacy.html` — политика конфиденциальности для формы обратной связи.
- `404.html` — страница ошибки 404.
- `styles.css` — общие стили сайта.
- `app.js` — интерактивность: меню, аккордеон, форма, reveal-анимации.
- `logo-mark.svg` — фирменный знак сайта.
- `favicon.svg` — иконка сайта.
- `robots.txt` — базовые настройки индексации.
- `.nojekyll` — отключение обработки Jekyll для простой публикации статических файлов.

- Бегущая строка брендов сохранена, но сделана глубже визуально за счет glass-эффекта и более аккуратного ритма.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub или откройте существующий.
2. Загрузите все файлы из этой папки в корень репозитория: `index.html`, `privacy.html`, `404.html`, `styles.css`, `app.js`, `logo-mark.svg`, `favicon.svg`, `robots.txt`, `.nojekyll`, `README.md`.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите `Save`.
6. После публикации GitHub покажет ссылку вида `https://username.github.io/repository/`.

## Важное про форму

GitHub Pages — статический хостинг, поэтому он не принимает файлы и заявки сам по себе. Сейчас форма формирует сообщение для WhatsApp. Если нужен настоящий прием заявок и Excel-файлов прямо с сайта, подключите внешний сервис форм или свой backend и замените обработчик формы в конце `index.html`.
